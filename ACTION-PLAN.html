The model every task below is ranked by

Measured, not asserted. "Associates with" throughout, never "causes".

  1. Distance is 47% of rank and the curve is spent by two miles. No task moves this.
  2. Primary category is a gate. All four are Cannabis store. Not the problem for any of them.
  3. Review mass is the strongest residual predictor (ρ −0.386, n=353). Direction unproven.
  4. Survive when reviews are held constant: rating (−0.176), service-options count (−0.171), claimed (−0.169), and not pointing the listing at the homepage (+0.148 = worse).
  5. Null under control, so never sold as a rank lever: citations (ρ 0.018 single-location), landing-page and root referring domains, rendered text, H1, NAP on page, JSON-LD, photos, attribute count, hours, Q&A, category count, name keywords on the main queries.

So the task order is always: listing fields that survive control → the review engine → outright defects that are free to fix → citation hygiene for correctness only → accept geography.

Task list

A. The listing — cheap, and these are the fields that survive control

Set a weekly cadence of replying to every review and asking at the counter. Do not promise a rank outcome for this; the direction of the reviews-to-rank relationship is not proven in this data.

  1. Set the canonical on /dispensary-locations/new-buffalo to itself and the title to "High Society Weed Dispensary New Buffalo". Fix the /dispensary-locations index canonical the same way. Verify with a plain fetch: the canonical host must be highsocietydispo.com.

If the store page cannot be fixed this week, move the listing to /shop/new-buffalo (no trailing slash), which is already correct. Never point it at the homepage: that associates with a worse residual.

The platform task that fixes nine clients at once

Staging hostnames are in the live head of nine of 29 client locations, ten with HPC Oxnard found today: *.[agency-staging-host] and [agency-staging-host]. The High Society one is the only dead canonical; the rest are stylesheet, script or link references to a host that should never appear in production. One release check that fails a build on either string in any emitted page clears the whole list. Do this before any per-client page work.

Second platform task: location pages must self-canonicalise. Four clients currently do not (High Society New Buffalo → dead staging host; Flora Terra 4th Street and Empire → homepage; Root'd In The 510 → homepage plus noindex). Third: the age gate. 17 of 29 clients render under 1,500 characters. Overlay, not replacement. Not proven to cost rank; proven to leave sites with no H1 and no discoverable pages.
